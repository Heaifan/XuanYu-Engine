# WAVE-2.5 Consumer Migration Integration Specification

## Goal

Integrate the exact D1 Camera/Picking/Gizmo consumer commit and the exact D2
Map Geometry/Region/Road/Marker consumer chain on the common WAVE-2.5 baseline.
The result is a consumer-layer integration only: all seven consumers coexist
under one router, one arbitration decision, one lifecycle, one cancellation
path, and one capture coordinator. Production Input Route remains unchanged.

## Fixed Git inputs

- Baseline: `00d8f147b1ffda5eabab2ae3a308f32c00b16258`
- D1: `01a84edfd38244e95f0d9d2966178ad189140b2b`
- D2 chain tip: `924ab09e0dac4a559958fbe70109e05530d8c34a`
- Integration branch: `feat/wave-2.5-consumer-migration-integration`

The branch must prove baseline ancestry before integration. D1 is integrated
first; the complete D2 chain from D1 through the stated tip is then integrated.
D1 and D2 source branches are not modified.

## Architecture contract

The router receives one ordered consumer registry but makes one explicit
candidate/arbitration decision for each Pointer Pressed. Eligibility combines
the active Tool/Mode and the consumer Hit/CanClaim result; a consumer is not
allowed to win merely because it was visited first. Once selected, the owner is
fixed until Commit or Cancel. The valid owners are Camera, Picking, Gizmo,
MapGeometry, Region, Road, and Marker. Snap is a helper/constraint of the
selected business owner and is never an owner or arbitration candidate.

`ViewportGestureLifecycle.Current` remains the only lifecycle fact source.
`ViewportGestureState` may project it, but no consumer may add Active, Dragging,
Capture, or Cancel state. All Escape/explicit Cancel, CaptureLost, FocusLost,
WindowDeactivated, ToolChanged, ModeChanged, and ViewportDisposed paths use the
same exactly-once terminal cleanup: owner Cancel, temporary-state cleanup,
capture release, owner clear, lifecycle Idle. A repeated Cancel is a no-op and
cannot Commit.

## Non-goals and prohibited scope

Do not modify VulkanNativeHost, Win32ViewportHost, Production Viewport,
Production Input Route, Vulkan Renderer, Composition, WAVE-3, public Schema, or
the C-route input model. Do not add host wiring. The six C-route gaps remain
registered: Delta, X1/X2, Horizontal Wheel, Avalonia Capture Source, Timestamp,
and Device Type.

## Acceptance evidence

The integration must include tests for every cross-arbitration pair requested by
the task, Snap non-preemption, both D1/D2 cancellation handoffs, consecutive
cross-consumer gestures, CaptureLost recovery, and Tool/Mode release. It must
also run the D1, D2, Phase-1, Router, Cancellation, Platform Parity, migration
baseline, ARCH-A, ARCH-VIEWPORT, 5+100, diff-check, and solution-build gates.
Known baseline failures are reported separately; New Regression must be zero.
