## Goal

建立平台无关的 Viewport 输入路由核心，使一个主动 Gesture 在任意时刻只有一个业务 Owner。

本任务只建立 Router / Owner arbitration 与契约测试，不把 NativeControlHost 或 Avalonia Viewport 生产入口接进新 Router。

## Frozen architecture

```text
EditorPointerEvent
        ↓
ViewportInputRouter
        ↓
Owner Arbitration
        ↓
ONE active gesture owner
```

核心约束：

1. 一个主动 Gesture 只能有一个 Owner。
2. Owner 一旦建立，在终止前保持稳定；Move 不得被其他消费者抢走。
3. 无 Owner 时才允许新的 Press/gesture-start 参与仲裁。
4. 终止事件只交给当前 Owner，不做多消费者 fan-out。
5. 无消费者 Claim 时 Router 保持无 Owner。
6. Passive observation 与 mutating gesture ownership 必须分离；观察者不得获得编辑权。
7. 不得凭空改变当前 Camera / Gizmo / Map Geometry / Picking 的现有优先语义。必须先从现有 route policy 与 tests 导出 priority matrix，再编码契约。

- Router 不依赖 Native/Avalonia 类型
