# WAVE-2.5 Consumer Migration Integration Plan

**Spec:** `docs/superpowers/specs/2026-09-24-wave-2.5-consumer-migration-integration.md`

## Task 1: Establish and prove the integration base

- Verify the branch, clean worktree, remote, baseline, D1 exact commit, and D2
  exact chain.
- Record changed-file manifests for D1 and every D2 commit.
- Merge D1, then merge the complete D2 chain with conflict resolution limited
  to the router/consumer integration contract.
- Confirm forbidden host, renderer, production-route, composition, and WAVE-3
  paths did not enter the result.

## Task 2: Define one cross-domain consumer registry and arbitration contract

- Register Camera, Picking, Gizmo, MapGeometry, Region, Road, and Marker under
  one Router instance.
- Make arbitration explicit and deterministic across Tool/Mode/Hit/Eligibility;
  no sequential `Handle()` winner-by-order behavior.
- Preserve each D1/D2 consumer's frozen business behavior and keep Snap as a
  selected-owner helper.
- Add focused tests for all seven cross-domain conflicts and Snap non-preemption.

## Task 3: Prove unified lifecycle, cancellation, and capture

- Route Begin/Update/Commit/Cancel through `ViewportGestureLifecycle.Current`.
- Verify Escape, CaptureLost, FocusLost, WindowDeactivated, ToolChanged,
  ModeChanged, and ViewportDisposed use one exactly-once terminal path.
- Add tests for repeated Cancel, cancel-without-commit, D1-to-D2 and D2-to-D1
  handoff, consecutive gestures, and capture recovery.

## Task 4: Record C-route gaps and run gates

- Record the six unchanged C-route gaps and assess BLOCK E versus BLOCK Final
  Gate without implementing them.
- Run D1, D2, Phase-1, Router, Cancellation, Platform Parity, Integration,
  migration baseline, ARCH-A, ARCH-VIEWPORT, 5+100, solution build, and
  `git diff --check` serially.
- Compare known baseline failures and prove New Regression is zero.

## Task 5: Atomic delivery

- Create one atomic integration commit after fresh verification.
- Push `feat/wave-2.5-consumer-migration-integration` and verify remote tip,
  ahead/behind, and clean worktree.
- Report consumer integration as `PASS / CONSUMER-INTEGRATED` only if all
  applicable gates pass; state explicitly that Production Input Route remains
  untouched and requires WAVE-2.5-E.
