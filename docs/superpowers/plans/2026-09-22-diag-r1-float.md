# DIAG-R1-FLOAT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Upgrade the existing Editor Diagnostic Probe into a floating hover, lock, inspect, and AI-copy workflow without changing editor layout or XYUI source files.

**Architecture:** Keep probing in `XuanYu.Editor.UI/Diagnostic`. Resolve the deepest Avalonia visual first, derive semantic identity and XYUI source from the canonical type map, then project a read-only snapshot into an Overlay-owned preview/card/detail popup. Clipboard output is generated by a dedicated formatter and never defaults to JSON.

**Tech Stack:** C# 13, .NET 10, Avalonia 12.0.4, existing XuanYu Editor UI, xUnit headless UI tests.

**Spec:** User-provided DIAG-R1-FLOAT frozen specification in the task conversation.

## Global Constraints

- All hand-written `.cs` and `.axaml` files remain at or below 100 lines.
- Diagnostic remains Editor infrastructure and does not modify `xyui/`.
- XYUI indices come from the existing canonical identity/type map; no second user-facing numbering system is introduced.
- Overlay content must not change business layout, consume non-interactive input, or replace existing DebugId behavior.
- R1 excludes layout warnings, runtime property editing, binding inspection, profiling, and event tracing.

## Review Focus

- A DebugId-free internal `TextBlock` is still selectable and reports its real type.
- Hover updates the preview but a locked target remains stable until Escape or close.
- XYUI controls resolve from canonical mapping while native/custom/unknown controls remain explicitly unmapped.
- Copy AI diagnosis is Chinese, structured plain text and contains no fabricated padding/state values.
- Overlay and floating cards preserve target bounds, scroll extent, and normal control input.
