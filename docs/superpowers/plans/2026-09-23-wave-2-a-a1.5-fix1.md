## Goal

修正 A1.5-R0 的实验条件，在不触碰生产 Viewport 的前提下重新裁决：

`Vulkan GPU image -> Avalonia GPU Composition -> Avalonia Overlay`

## Scope

仅允许修改独立 Composition Spike 及其测试/报告。

1. Spike-only 升级到 Avalonia 12.1.3；不得升级生产工程。
2. Windows 明确强制 Avalonia Vulkan rendering backend，不得继续依赖默认 backend。
3. 使用 12.1.3 GPU interop API，显式传递 Vulkan image layout。
4. 启动日志必须打印：
   - Avalonia version
   - 实际 rendering backend
   - GPU/device
   - SupportedImageHandleTypes
   - SupportedSemaphoreTypes
   - VulkanOpaqueNtHandle YES/NO
5. 真实 GPU image 必须进入 `CompositionSurfaceVisual`。
6. 同一 Avalonia Window 内普通 Button 必须覆盖 Vulkan 内容并通过 Hover/Click。
7. Resize 后必须重建 GPU 资源并继续正确显示。
