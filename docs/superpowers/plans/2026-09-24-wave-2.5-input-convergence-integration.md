**Goal:** Integrate A/B/C into one Viewport input router, one owner source, one gesture lifecycle, one cancellation pipeline, and one capture protocol without migrating business consumers.

## Global Constraints

- No Camera, Picking, Gizmo, Map Geometry, Region, Road, Marker, Snap consumer migration.
- No Production Input Route switch, NativeControlHost deletion, Win32ViewportHost deletion, Vulkan Composition refactor, or WAVE-3.
- `EditorPointerEvent` remains the only platform-neutral boundary.
- Owner and cancellation state must have one source of truth.
- C GAPs remain explicitly recorded: Delta, X1/X2, Horizontal Wheel, Avalonia Capture Source, Timestamp, Device Type.
- Every handwritten `.cs`, `.axaml`, and `.js` file remains at most 100 physical lines.

## Review Focus

- Router and lifecycle must not retain independent Cancel or Owner fields.
- CaptureLost, FocusLost, and WindowDeactivate must enter the same exactly-once cancellation path.
- Native and Avalonia adapters must produce equivalent `EditorPointerEvent` semantics without platform branches in core routing.
- Repeated Cancel and post-cancel Begin must be safe.
- Integration must not silently change existing migration-baseline known failures.
