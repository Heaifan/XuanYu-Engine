## Goal

建立统一的 Gesture / Interaction lifecycle，使所有未来 Viewport Consumer 都能通过同一套终止语义完成 Complete 或 Cancel，避免 capture、preview、drag session、owner 残留。

本任务建立 lifecycle contract + coordinator + tests，不把现有 Region/Road/Camera/Gizmo 生产路径强制迁移进来。

## Frozen lifecycle

```text
Idle
 ↓ Begin
Active
 ├─ Released --------> Complete
 ├─ CaptureLost -----> Cancel
 ├─ FocusLost -------> Cancel
 ├─ Cancel ----------> Cancel
 └─ WindowDeactivated> Cancel

任何终止路径：
session terminal
owner releasable
capture releasable
preview/session cleanup requested
且只能终止一次
```

## Required semantics

1. `Released` 是正常 Complete 路径。
2. `CaptureLost` / `FocusLost` / `Cancel` / `WindowDeactivated` 是 Cancel 路径。
3. 同一 interaction 只能 terminal 一次。
4. Cancel 后再收到 Released 不得二次 Complete。
5. Repeated Cancel 必须幂等。
6. 终止结果必须明确表达：
   - interaction inactive
   - owner should release
   - capture should release
   - preview/session cleanup required
7. 不允许 consumer 各自发明不同的 cancellation state machine。
