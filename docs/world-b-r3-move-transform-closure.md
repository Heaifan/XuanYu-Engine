# WORLD-B-R3 移动变换闭环报告

版本：v0.2.20.6-rz
日期：2026-07-26
分支：feat/WORLD-B-editor-interaction
阶段：WORLD-B-R3：移动变换闭环

## 裁定

WORLD-B-R3 已完成移动变换闭环：单轴移动、XY / XZ / YZ 平面控制柄、Preview / Commit / Cancel、Undo / Redo、跨 Region、输入互斥和中文 IPO 真机清单均已落库。

本轮继续复用 `MoveGizmoLayout`、`TransformSession`、`EditorStateOwner`、`SceneStateOwner` 和 `GlobalWorld`。不新增第二套 Gizmo 快照、Transform 权威、Selection 权威或 Region 归属维护。

## 实现变化

- `MoveGizmoLayout` 增加 XY / XZ / YZ 平面控制柄投影和命中，轴命中优先于平面命中。
- `MoveGizmoPlane` 用同一组屏幕四边形作为可视面片和 Picking 面片来源。
- `UiVm.MoveGizmo` 在平面命中后复用当前移动会话，构造 `MoveGizmoDragConstraint.Plane`。
- Vulkan `scene.vert` 绘制中心标记、三个平面面片和三根轴杆；`CmdDraw` 顶点数从 21 扩展为 39。
- `UiVm.UpdateViewportFrame` 将 Resize 汇入移动取消路径，恢复 Begin 位置并清除 Preview。
- `VulkanClearFrameOwner.Matrix` 拆出矩阵辅助，保持 Draw 分部职责集中。

## 中文 IPO 真机验收清单

#### 测试项目：XY 平面移动

- 序号：01
- 路径：左侧“层级” → 选择实体；顶部工具栏 → “移动”；中央视口；右侧“检查器”
- 输入 I：
  - 已选中一个可见实体。
  - 中央视口显示移动控制柄。
- 过程 P：
  1. 单击顶部工具栏中的“移动”。
  2. 在中央视口按住 XY 平面控制柄。
  3. 沿该平面明显拖动。
  4. 松开鼠标左键。
  5. 查看右侧“检查器”中的位置。
- 输出 O：
  - 实体只改变 X、Y。
  - Z 保持不变。
  - 画面位置与“检查器”数值一致。
  - 只产生一次提交。

#### 测试项目：XZ 与 YZ 平面移动

- 序号：02
- 路径：顶部工具栏 → “移动”；中央视口；右侧“检查器”
- 输入 I：
  - 已选中实体并显示移动控制柄。
- 过程 P：
  1. 按住 XZ 平面控制柄拖动并提交。
  2. 确认 Y 未变化。
  3. 按住 YZ 平面控制柄拖动并提交。
  4. 确认 X 未变化。
- 输出 O：
  - XZ 只修改 X、Z。
  - YZ 只修改 Y、Z。
  - 不出现第三轴漂移。

#### 测试项目：Escape 取消移动

- 序号：03
- 路径：顶部工具栏 → “移动”；中央视口；键盘 → Escape
- 输入 I：
  - 已记住实体移动前的位置。
- 过程 P：
  1. 按住任一单轴或平面控制柄。
  2. 明显拖动但不要松开鼠标左键。
  3. 按 Escape。
  4. 松开鼠标左键。
- 输出 O：
  - 实体恢复到拖动前位置。
  - 延迟松开鼠标不会重新提交。
  - “撤销”不会出现本次已取消操作。

#### 测试项目：“撤销”和“重做”

- 序号：04
- 路径：顶部工具栏 → “移动”；顶部工具栏 → “撤销”“重做”
- 输入 I：
  - 已完成一次明显移动。
- 过程 P：
  1. 记录移动后的实体位置。
  2. 单击“撤销”。
  3. 查看实体和“检查器”位置。
  4. 单击“重做”。
  5. 再次查看实体和“检查器”位置。
- 输出 O：
  - 一次“撤销”回到移动前。
  - 一次“重做”恢复移动后。
  - 层级、检查器、视口和控制柄一致。

#### 测试项目：跨区域移动

- 序号：05
- 路径：左侧“层级” → 区域节点；顶部工具栏 → “移动”；右侧“检查器”
- 输入 I：
  - 存在靠近区域边界的测试实体。
- 过程 P：
  1. 选中测试实体。
  2. 使用“移动”将其拖过区域边界。
  3. 松开鼠标提交。
  4. 查看左侧“层级”的区域归属。
  5. 查看右侧“检查器”的路径、区域和位置。
  6. 分别单击“撤销”和“重做”。
- 输出 O：
  - 实体进入正确区域。
  - 实体编号和选择保持不变。
  - “撤销”“重做”能够在两个区域之间正确恢复。

#### 测试项目：移动期间输入互斥

- 序号：06
- 路径：顶部工具栏 → “移动”；中央视口
- 输入 I：
  - 已开始拖动移动控制柄。
- 过程 P：
  1. 保持移动拖动状态。
  2. 尝试按鼠标中键。
  3. 尝试滚动鼠标滚轮。

- 输出 O：

  - 选择不改变。
  - 工具不切换。
  - 当前移动会话保持唯一。
