# WORLD-C-R4-D2-F1 中文 IPO 真机验收卡

版本：`v0.2.21.21-fix`

#### 测试项目：R1 十三角场景完整显示回归

- 序号：01
- 路径：`文件` -> `打开` -> `samples/world-c-r1-ten-triangles.xyscene`
- 输入 I：
  - 未设置 `XUANYU_D2_STATIC_MODEL_DEMO`。
  - 当前分支为 `feat/WORLD-C-scene-authoring`。
- 过程 P：
  1. 运行 `run.bat`。
  2. 通过 `文件` -> `打开` 打开 `samples/world-c-r1-ten-triangles.xyscene`。
  3. 不执行 Dolly，先观察默认视口。
  4. 再执行一次轻微 `环绕`，观察所有实体显示是否稳定。
- 输出 O：
  - 十个 Legacy 三角实体应按场景内容显示，不应只剩一个局部三角。
  - 不需要继续缩放才能完整显示。
  - 背景、网格、原点不遮挡实体填充。
  - 日志无 Vulkan fatal 或 validation 级错误。

#### 测试项目：D2 受控静态模型完整显示

- 序号：02
- 路径：`XUANYU_D2_STATIC_MODEL_DEMO=1` -> `run.bat` -> 默认视口
- 输入 I：
  - PowerShell 中设置 `$env:XUANYU_D2_STATIC_MODEL_DEMO="1"`。
  - 不打开外部 GLB，不点击导入按钮。
- 过程 P：
  1. 运行 `run.bat`。
  2. 观察默认视口中 D2 受控静态模型。
  3. 不执行 Dolly，确认初始画面。
  4. 执行一次轻微 `环绕` 和一次轻微 Dolly。
- 输出 O：
  - 静态模型两个 Primitive 都应可见。
  - 基础颜色差异应可辨识。
  - 模型不应被背景整片遮挡。
  - Dolly 前后不应出现“缩放后才完整显示”的状态跳变。

#### 测试项目：选择与 Bounds 轮廓同步

- 序号：03
- 路径：`层级` -> 选择当前实体 -> `移动` / `旋转` / `缩放`
- 输入 I：
  - D2 受控演示模式已启动。
  - 当前实体处于选中状态。
- 过程 P：
  1. 点击 `移动`，拖动一个轴后取消或提交。
  2. 点击 `旋转`，执行一次小角度预览。
  3. 点击 `缩放`，执行一次轻微缩放预览。
- 输出 O：
  - 模型、Bounds 轮廓和 Gizmo 使用同一 Transform。
  - Bounds 轮廓不滞后、不残留、不停在旧位置。
  - Gizmo 屏幕尺寸不因模型大小变化。
