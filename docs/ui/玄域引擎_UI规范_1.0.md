## 一、首批冻结参数（来自治理实施计划第三章，D0 起生效）

> 以下数值为本轮第一版实施合同。只能通过正式规范变更流程调整，实施 AI 不得自行改动。

### 1.1 字体与字号

**编辑器字体回退链**（已冻结）：

```text
Microsoft YaHei UI → Segoe UI → Noto Sans CJK SC → 系统无衬线字体
```

**字号 Token 表**（已冻结，D2 必须建为 Token）：

| Token | 字号 | 标准行高 | 用途 |
|---|---:|---:|---|
| `Font.Meta` | 10 DIP | 14 DIP | 类型标签、极次要元信息 |
| `Font.Small` | 11 DIP | 16 DIP | 辅助文字、次级状态 |
| `Font.Label` | 12 DIP | 18 DIP | 字段标签、按钮文字、菜单辅助信息 |
| `Font.Body` | 13 DIP | 20 DIP | 正文、字段值、树、列表、日志 |
| `Font.Section` | 14 DIP | 22 DIP | 二级页签、分组标题 |
| `Font.Title` | 16 DIP | 24 DIP | 面板主标题、弹窗标题 |
| `Font.Page` | 20 DIP | 28 DIP | 欢迎页与页面标题 |
| `Font.Display` | 24 DIP | 32 DIP | 启动器或大型结果标题 |

**约束**（已冻结）：顶层页签 13；地图编辑器二级页签 14；字段标签 12；字段值 13；普通按钮 12；类型标签 10～11；编辑器区域禁止响应式缩放；禁止 Light；Regular 正文 / Medium·SemiBold 页签分组 / Bold 仅页面主标题。

**审订备注**：`Font.Small=11` 当前仓库无使用点；分组标题现状 12（Ui.axaml TextBlock.section）与 F3 合同"13 半粗"冲突，D1 定夺映射到 Section=14 或 Label=12。

### 1.3 间距、圆角与控件尺寸（已冻结）

- 间距主网格：`4 / 8 / 12 / 16 / 24 / 32 DIP`；受控半级 `2 / 6 DIP`
- 圆角：小 `3` / 标准 `6` / 大 `10 DIP`；编辑器主体 3～6；10 仅欢迎页/启动器/游戏大容器；禁大量胶囊按钮
- 控件高度：紧凑 `24` / 标准 `28` / 强调 `32 DIP`
- 最小点击热区：紧凑区 `24×24` / 常规按钮与独立图标 `28×28` / 游戏触控 `36×36 DIP`
- 常用宽度等级：`64 / 96 / 128 / 160 / 240 DIP`；检查器标签列默认 `96`；字段最小 `128`；表单纵向切换阈值 内容宽 `<360`；禁止为单一控件创造新宽度等级

### 1.4 面板与窗口阈值（已冻结）

| 项目 | 合同 |
|---|---|
| 应用最小窗口 | `1024×640 DIP` |
| 推荐初始窗口 | `1360×820 DIP`（≤工作区可用范围） |
| 左侧层级树最小宽度 | `220 DIP` |
| 右侧工作面板最小宽度 | `300 DIP` |
| 右侧标准宽度 | `340 DIP` |
| 底部日志最小高度 | `120 DIP` |
| 视口最小可用区域 | `480×320 DIP` |
| 属性表单纵向切换阈值 | 内容宽 `< 360 DIP` |
| 面板紧凑模式阈值 | 内容宽 `< 320 DIP` |

**收缩顺序**（已冻结）：紧凑间距 → 表单纵向 → 折叠次要工具区 → 隐藏低优先级辅助面板 → 保留恢复入口 → 不得挤压关键文字/字段/热区。

### 1.5 图标合同（已冻结）

16×16 标准视口 / 20×20 工具栏独立操作 / 线性笔画 1.5 / 视觉中心校正 / 同组统一端点转角笔画留白 / 禁 Emoji·Unicode·系统字体符号 / 线性为主，锁定·显示·隐藏·警告·错误·选中允许局部填充或形态变化 / 状态不只靠颜色 / 无文字图标必须 Tooltip / 图标本体可小于热区但热区不缩小。

### 1.6 边框、阴影与焦点（已冻结）

普通边框 1 DIP；拖拽插入线 2 DIP；键盘焦点框 2 DIP 外偏移 1；焦点≠选中视觉；焦点框不裁切；普通面板/按钮/列表项禁阴影；阴影仅弹窗/菜单/Tooltip/浮动工具条；悬浮层阴影首版：垂直偏移 4 / 模糊 12 / 低透明黑约 14%。

### 1.7 动效（已冻结）

悬停/选中 80～120 ms；展开/折叠 120～160 ms；拖动/缩放/滚动/Gizmo/面板调整直接跟手不加迟滞；禁弹跳/强发光/长缓动/大面积渐变/装饰性循环动画。

### 1.8 标准菜单结构与弹窗按钮顺序（D1 必做项，D0 登记草案）

- 顶层菜单默认顺序：`文件 → 编辑 → 视图 → 地图 → 工具 → 窗口 → 帮助`（只在功能存在时显示，不凑空菜单）
- 弹窗按钮：底部右对齐 `取消 → 次要操作 → 主要操作`；危险 `取消 → 危险操作`；危险按钮不得默认焦点；Esc 取消；Enter 仅安全主操作
