# 玄域引擎 UI 真机基线清单（ARCH-UI-SPEC-R1-D0）

> **治理编号**：ARCH-UI-SPEC-R1-D0
> **生成日期**：2026-08-05
> **基线**：v0.2.24.36-rz（0380192）——治理整改开始前的真机状态快照
> **用途**：① 记录整改前已知真机问题（D0 特别登记）；② 作为 D3~D6 各轮真机验收的共用清单；③ A1 最终真机验收的主清单。
> **规则依据**：《玄域引擎 UI 规范 1.0》（正式规范，UI Spec 1.0）——本清单只引用规范章节，不重复定义规则。
> **原则**：自动化通过 ≠ 真机通过；验收以中文 IPO 格式执行；「最大化正常 ≠ 通过」，初始非最大化窗口（推荐 1360×820）是主验收尺寸。

## 一、验收覆盖矩阵（每个整改轮 + A1 必须覆盖）

| 维度 | 覆盖项 |
|---|---|
| DPI | 100% / 125% / 150% / 200%（系统缩放，禁止物理像素手工补偿） |
| 窗口状态 | 初始非最大化（推荐 1360×820）/ 最大化 / 恢复 / 最小窗口（1024×640）/ 连续拖动缩放 |
| 分辨率 | 1080p（必验）/ 2K（条件）/ 4K（条件或等效缩放） |
| 面板边界 | 左侧层级树 220 最小 / 右侧面板 300 最小 / 底部日志 120 最小 / 视口 480×320 最小 |
| 高 DPI 窄窗口 | 面板最小宽度下文字不遮挡、不重叠、不截断关键内容、控件可点击 |

> 每轮真机记录格式：序号 / 路径（UI 真实中文名与按钮名）/ 输入 I / 过程 P / 输出 O；输出必须可由画面、状态、日志、数据明确判定，禁止「正常/通过/无问题」式结论。
