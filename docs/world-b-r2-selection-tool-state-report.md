# WORLD-B-R2 选择与工具状态闭环报告

版本：v0.2.20.4-rz

分支：feat/WORLD-B-editor-interaction
阶段：WORLD-B-R2：选择与工具状态闭环

## 裁定

本轮只收口编辑器选择状态、工具状态和输入抢占。不进入 Rotate / Scale 数学、Inspector 数值变换、多选、框选算法、WarCore、Soldier、Faction、Organization 或战斗。

R2 复用既有 `EditorStateOwner` 作为唯一 Selection / Tool Owner，不新增 `SelectionService`、`ToolService`、`EditorInteractionManager` 或第二套全局状态。

## 实现变化

- `UiVm.InputGuards` 新增输入门禁：活动移动会话或活动相机会话期间禁止 Picking、选择写入和工具切换。
- `UiVm.Picking` 只允许顶部“选择”工具在无活动会话时写入 Selection；“移动”状态下点击空白不再清除选择。
- `UiVm.Tool` 拒绝“框选”“旋转”“缩放”进入虚假活动态，保持当前真实工具并给出未实装提示。
- `UiVm.Selection` 在活动输入会话期间拒绝层级 / 项目树选择写入，避免 UI 高亮和唯一 Owner 分裂。
- `UiVm.SelectionValidity` 根据 World 权威 `TryGetEntity` 清理已经失效的 `EntityId` 选择；不根据层级节点是否显示猜测。
- `UiVm.Interaction` 与 `UiVm.InteractionPointer` 要求移动会话必须满足“当前工具=移动、有有效选择、无相机会话”。

## 中文 IPO 真机验收清单

#### 测试项目：左侧“层级”选择同步

- 序号：01
- 路径：左侧面板 → “层级”；右侧面板 → “检查器”
- 输入 I：
  - 场景内存在“基础测试实体”和“测试实体 02”。
- 过程 P：
  1. 在左侧“层级”单击“基础测试实体”。
  2. 查看右侧“检查器”。
  3. 再单击“测试实体 02”。
  4. 再次查看右侧“检查器”。
- 输出 O：
  - 左侧每次只有一个实体高亮。
  - 右侧“检查器”始终显示当前高亮实体。
  - 不出现上一实体信息残留。

#### 测试项目：中央视口选择同步

- 序号：02
- 路径：顶部工具栏 → “选择”；中央视口；左侧“层级”
- 输入 I：
  - 中央视口可见多个实体。
- 过程 P：
  1. 单击顶部工具栏中的“选择”。
  2. 在中央视口单击一个可见实体。
  3. 查看左侧“层级”高亮。
  4. 查看右侧“检查器”名称。
- 输出 O：
  - 视口命中的实体在左侧“层级”同步高亮。
  - 右侧“检查器”显示同一实体。
  - 只存在一个活动选择。

#### 测试项目：空白点击取消选择

- 序号：03
- 路径：顶部工具栏 → “选择”；中央视口空白区域
- 输入 I：
  - 当前已经选中一个实体。
- 过程 P：
  1. 确认左侧“层级”有一个高亮实体。
  2. 在中央视口没有实体的位置单击鼠标左键。
  3. 查看左侧“层级”。
  4. 查看右侧“检查器”。
- 输出 O：
  - 左侧实体高亮清除。
  - 右侧不再显示上一实体的检查内容。
  - 变换控制柄隐藏。
  - 顶部仍保持“选择”工具。
